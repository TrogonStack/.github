## Trogon Stack 🦜

Open-source building blocks for event-driven systems.

### TrogonAi

**[TrogonAi](https://github.com/TrogonStack/trogonai) is a distributed agentic platform for
coordinating autonomous AI agents across services and runtimes.**

Building reliable multi-agent systems today means stitching together queues, databases,
orchestrators, and custom glue code. TrogonAi replaces that patchwork with distributed architecture
primitives: clear service boundaries, durable coordination, observable execution, and horizontal
scale. It handles agent lifecycle, inter-agent communication, and durable state, so teams can focus
on agent behavior instead of distributed systems plumbing.
